# AI Employee Vault

Autonomous AI Employee system built for the 2026 Personal AI Employee Hackathon.

## Concept
This project simulates a full-time AI employee that:
- Receives tasks
- Classifies intent
- Executes plans
- Logs actions
- Requests approvals
- Completes work autonomously

## Structure
- Inbox/ — Incoming tasks
- Needs_Action/ — Requires clarification or approval
- Plans/ — Execution plans
- Pending_Approval/ — Awaiting human approval
- Approved/ — Approved tasks
- Rejected/ — Rejected tasks
- Done/ — Completed work
- Logs/ — Execution logs
